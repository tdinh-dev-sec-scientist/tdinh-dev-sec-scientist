## 🚀 About Me  

I'm a cybersecurity student focused on network security, threat detection, and turning research questions into working detectors and dashboards.  
My work bridges **network monitoring, covert-channel research, and cloud security auditing** — transforming attacker techniques into detection logic.

Some highlights:
- 🕵️ Co-authored **"The Invisible Tunnel,"** research on **IPv6 covert channels** using Extension Headers, Flow Label manipulation, and XOR-encrypted C2 data, paired with a **hybrid deep-learning detection system** (Autoencoder, Random Forest, One-Class SVM, LOF, RBF-SVM)  
- 🏆 Won **2nd Place, STEM category** at APSU's Student Research Symposium, and was selected to represent the university at the statewide **Posters at the Capitol** event  
- 🖥️ Built **NetWatch SOC**, a network security monitoring platform with deep packet inspection, **17 threat detectors mapped to MITRE ATT&CK**, a Flask REST API, and an analyst dashboard  
- 🔐 Developing **Account Access Auditor**, an **AWS IAM/S3/CloudTrail** configuration auditor in Python  
- 🎤 Mentored **30 students** as a Peer Leader for an honors "University Success" course, including sharing cybersecurity-awareness content with the cohort  

I love digging into how attackers hide in plain sight, and building the detection logic that finds them.
